👋 关于我

嗨，欢迎来到瓜子 Blog！我是一名热爱前端开发的工程师，目前专注于 Web 前端技术领域。

做这个博客的初衷很简单——想在互联网上有一个属于自己的角落， 记录学习过程中的点滴收获，也希望能帮助到正在走相似路的朋友。

取名「瓜子」，是因为这种小零食总让我想起悠闲的午后时光—— 泡一杯茶，抓一把瓜子，翻开一本书或者写点东西。博客也应该如此， 不需要太正式，不需要太严肃，轻松自在就好。

这个博客的技术栈非常简单：手写 HTML/CSS/JavaScript，使用 Marked.js 渲染 Markdown， Highlight.js 做代码高亮。没有复杂的构建工具，回归 Web 的本质。

🛠️ 技术栈

JavaScript / TypeScript React Vue.js Next.js Node.js HTML / CSS Tailwind CSS Git Docker PostgreSQL Figma VS Code

📝 关于本站

本站使用纯静态方式搭建，托管在 GitHub Pages 上。 所有文章内容以 Markdown 格式编写，通过 Marked.js 在浏览器端渲染。

设计上追求简洁易读，没有复杂的动画和多余的装饰。 响应式布局适配桌面端和移动端，无论在哪种设备上阅读，都有良好的体验。
